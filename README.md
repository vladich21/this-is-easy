# Замер скорости скачивания

Консольный скрипт делает **10 GET-запросов по очереди** к указанному адресу, дожидается полного тела каждого ответа и печатает среднее время, общий объём и скорость скачивания.

## Требования

- Node.js 18 или новее

Проверка версии:

```bash
node -v
```

Зависимостей нет, `npm install` не нужен.

## Запуск

```bash
node index.js "<url>"
```

Пример с файлом на 5 МБ (десять запросов скачают около 50 МБ):

```bash
node index.js "https://speed.cloudflare.com/__down?bytes=5000000"
```

Адрес может вести на картинку или любой другой файл по `http://` или `https://`. Если сервер отвечает перенаправлением (`301`, `302`, `303`, `307`, `308`), скрипт идёт по нему, но не больше пяти раз. Время и объём одного «запроса» включают всю такую цепочку.

На каждый запрос есть общий предел **120 секунд**. Если данных нет или скачивание не закончилось за это время, скрипт останавливается с ошибкой и не считает средние по неполной серии.

## Единицы

| Величина | Единица | Что означает |
| --- | --- | --- |
| Время запроса | миллисекунда (мс) | от отправки запроса до последнего байта тела |
| Общее время | секунда (с) | сумма десяти времён запросов |
| Объём | мегабайт (МБ) | `1 МБ = 1 000 000 байт` |
| Скорость | мегабит в секунду (Мбит/с) | `1 Мбит/с = 1 000 000 бит/с` |

Объём — это размер тел ответов, которые скрипт реально прочитал. Заголовки HTTP в него не входят. Скрипт просит сервер не сжимать ответ (`Accept-Encoding: identity`), чтобы для обычного файла объём совпадал с размером файла.

## Как считается скорость

```text
скорость (Мбит/с) = (общий объём в байтах × 8) / общее время в секундах / 1 000 000
```

В общее время входят только сами запросы. Пауза на печать строки в консоль между ними в скорость не попадает.

Среднее время — это сумма десяти времён, делённая на 10.

## Пример вывода

```text
Адрес: https://speed.cloudflare.com/__down?bytes=5000000
Запросов: 10, строго по очереди

# 1  HTTP 200  5.00 МБ  812 мс
# 2  HTTP 200  5.00 МБ  790 мс
...
#10  HTTP 200  5.00 МБ  805 мс

Среднее время запроса: 802 мс
Общий объём: 50.00 МБ
Общее время: 8.02 с
Скорость скачивания: 49.88 Мбит/с
```

Цифры зависят от канала и от того, какой файл вы указали.
